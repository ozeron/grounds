# Secret runtime and retirement review

Reviewed 2026-10-23 for M2 using **Bend 2.0.38**, Bun 1.3.14 and Apple Clang
21. Generated C and JS are retained under
`~/.codex/artifacts/grounds/2026-10-23/m2/runtime/`; `manifest.json` binds
source inputs, generated bytes and compiler/runtime executable hashes.
The parent directory retains each exact generation command, guard report and
log. Default generated Bun evaluation retains JIT; compiler-only GC/JIT
settings, where used, are recorded separately. No alternate runtime is silently
substituted for default evaluator acceptance.

**Live-secret use is blocked.** This review permits synthetic-key component
interoperability only. It inspects emitted C/JS, not all optimized machine
instructions, microarchitectures, scheduling or Bun JIT tiers. Passing vectors
or timing distributions cannot prove constant-time execution. No dudect result
or physical-erasure approval is claimed.

## Findings and dispositions

Each row has one of the M2 dispositions. A mitigation describes its limited
effect; it is not a whole-runtime constant-time claim.

The physical-erasure blocker applies to live secrets. M2's synthetic-key exit
may close with this explicit disposition; it cannot authorize production keys,
real credentials or hostile multi-tenant timing exposure. This supersedes the
unresolved-only checkpoints in ECDSA_REVIEW.md, RSA_REVIEW.md and the cookie
review without retroactively changing their historical evidence.

## Storage and retirement contract

1. **Logical ownership.** M3 keeps one ephemeral offer per connection and one
   read/write owner per direction/epoch. `shared` consumes the private offer on
   success and failure. Imported private and CertificateVerify key wrappers are
   affine and signing consumes them, including invalid transcript/entropy paths.
   Reuse requires a separately supplied/imported owner, never a hidden global
   nonce/key cache. Trusted callers must not unwrap/reconstruct constructors or
   copy their ordinary inner byte lists to bypass this discipline.
2. **Entropy.** Generate every connection/replacement share through
   `wire_random_bytes`. X25519 clamps its one 32-byte draw. P-256 rejects zero or
   >=n instead of reducing; each retry draws 32 new bytes. ECDSA uses RFC 6979
   without host nonce draws. RSA-PSS takes 32 fresh salt bytes and k fresh
   candidate blinding bytes; rejected candidate attempts consume the owner and
   require a fresh owner/draw. M3's Hello random is another 32-byte draw.
3. **Retirement.** Do not log or expose scalar, nonce K/V, CRT, shared, traffic,
   HMAC pad or Finished bytes. Test diagnostics contain synthetic inputs only.
   Authentication/invalid-input/exhaustion failures return a closed traffic
   successor; consuming a Finished/signing stage returns no secret successor.
   KeyUpdate consumes the previous epoch and retains only the derived epoch.
   Explicit close drops live fields. UpdateLimit is intentionally recoverable;
   a fatal decision must call close. M3 must drop every remaining direction,
   transcript, application-derivation stage and socket on alert/deadline/EOF/
   cancellation. No composed connection exists yet, so those paths remain M3.
4. **What affine ownership does not guarantee.** It restricts ordinary typed
   reuse, not confidentiality from arbitrary Grounds code, debugger/core dumps,
   heap sharing, GC/JIT, registers, OS storage or physical remanence. It cannot
   prove constant-time arithmetic, uniqueness of caller-supplied entropy or
   physical erasure. A live-secret implementation needs a runtime/backend
   contract covering these properties, followed by new generated/optimized-code
   review; replacing ordinary lists with another ordinary container is not a fix.

## References and evidence limits

Arithmetic/encoding follows existing Grounds references plus RFC 7748,
SEC 1 v2.0, RFC 6979, RFC 8017, FIPS 197, SP 800-38D, RFC 8439,
RFC 5869 and RFC 9846. No external crypto implementation is linked or called
by the new Bend path. Python cryptography/OpenSSL remain fixture/oracle tools.
The static evidence establishes inspected emitted behavior only; corpus
correctness, source-level masks and a normal timing sample cannot close the
live-secret runtime blockers.
